Arquivo editável: examples/replica-imagem.planta.json.

## Informações a confirmar

- Cores, bitolas, quantidade e funções dos fios não são distinguíveis na captura; não foram inventadas.
- Potências foram transcritas somente quando legíveis. Valores em branco significam a confirmar, não zero.
- A posição de algumas portas e símbolos é aproximada. Tipos ambíguos são identificados nas notas de cada elemento.
- QGBT, DG e quadro inferior são uma interpretação dos símbolos de distribuição; a identificação original deve ser conferida.
- Linhas diagonais foram reproduzidas como vistas, inclusive passagens externas. Não foram substituídas por roteamento ortogonal.
- Não foram acrescentados ramais automaticamente para completar pontos cuja ligação não é visível.

Circuitos 1–24 e 50 organizam referências numéricas vistas ou parcialmente identificadas. A associação de alguns pontos é provisória e consta das notas. Demais campos elétricos ilegíveis são nulos (a confirmar). Muitos pontos permanecem sem circuito/ramal para evitar completar a imagem por suposição.

As passagens visíveis foram registradas como percursos sem fios individualizados, pois não há leitura confiável da bitola, cor, função e quantidade dos condutores. Use Fios e cabos para preencher esses dados após conferência. O relatório não deve ser usado como quantitativo de fiação concluído.

A imagem original foi preservada em examples/reference/planta-original.png para comparação.

Os identificadores L-AREA, T01, J01, QD-INF etc. são identificadores de edição criados para esta réplica e não uma transcrição dos TAGs originais. Apenas legendas e referências legíveis foram preservadas como tais.
